mv - mueve los archivos y funciona para modificar el nombre de un archivo 
find - sirve para buscar un archivo con un nombre en especifico 
cd - abre directorios 
cd .. - regresa al diectorio anterior
cp - copia los archivos desde la ruta de origen a la de destino 
echo - sirve para agregar texto a un archivo de manera rapida y con un maximo de dos lineas 
nano - permite agregar muchas mas lineas de texto a un archivo y realizar mas acciones con el mismo }
ls - sirve para ver los archivos y directorios que se encuentran guardados en la ruta que estemos 
ls -a - funciona para ver archivos ocultos dentro del directorio 
ls -l funciona para ver los permisos fecha y hora de los archivos del directorio
cd ~ - sirve para regresar al directorio principal 
rm - elimina un archivo del directorio en el que estemos 
mkdir - crea un directorio
touch - crea un archivo 
pwd - muestra la ruta del directorio actual
